# PwC Cyber Security Consulting Job Simulation

**A virtual job simulation offered by PwC US through the Forage platform, covering core cybersecurity consulting disciplines across four tasks.**

---

## What This Is

This simulation replicates the kind of work performed by a cybersecurity consultant at PwC. Each task covers a distinct area of consulting practice — from assessing risk and reviewing secure development practices to evaluating IT controls and presenting findings.

This is an independent educational program completed through Forage. It is not employment or a client engagement.

---

## Simulation Structure

| Task | Title | Status |
|---|---|---|
| 01 | Risk Assessment | Not Started |
| 02 | Software Development Lifecycle (SDLC) | Not Started |
| 03 | IT General Controls (ITGC) | Not Started |
| 04 | Controls Testing Summary Presentation | Not Started |

## Frameworks and Concepts

Topics covered across the simulation include risk assessment methodology, the NIST Cybersecurity Framework, secure software development practices, IT general controls, and control testing documentation — all within the context of professional cybersecurity consulting.
