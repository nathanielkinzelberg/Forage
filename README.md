# Forage Job Simulations

**A collection of virtual job simulations completed through Forage, documented as professional portfolio projects.**

---

## What This Is

Each subfolder contains a separate Forage simulation — a structured, self-paced program that replicates the work of a professional role. These are independent educational programs, not internships or employment. Each is documented with task breakdowns, methodology, applied concepts, and findings.
